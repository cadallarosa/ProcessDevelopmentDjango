Plotly.js Subplots Example

1. Simple 2x2 Grid (Python makes_subplots equivalent)

2. Shared X-Axis (like SEC multi-channel)

Key Points for Plotly.js Subplots:

  • Domain-based: Define subplot positions using [xmin, xmax] and [ymin, ymax] (0 to 1)
  • Axis naming: x-axes: xaxis, xaxis2, xaxis3... Same for y-axes
  • Anchoring: Each axis must be anchored to its corresponding perpendicular axis
  • Grid helper: Use grid: {rows: 2, columns: 2} for automatic positioning
  • Shared axes: Point multiple y-axes to the same x-axis for stacked plots

Python make_subplots equivalent:

# Python Plotly
from plotly.subplots import make_subplots
fig = make_subplots(rows=2, cols=2)
fig.add_trace(trace1, row=1, col=1)
fig.add_trace(trace2, row=1, col=2)

# JavaScript Plotly equivalent (manual layout)
var layout = {
    xaxis1: {domain: [0, 0.45]},
    yaxis1: {domain: [0.55, 1]},
    xaxis2: {domain: [0.55, 1]},
    yaxis2: {domain: [0.55, 1]}
};
Plotly.newPlot('div', [trace1, trace2], layout);
