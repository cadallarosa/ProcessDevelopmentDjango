================================================================================
HOW BASE64 BECOMES NUMBERS
================================================================================

STEP 1: Base64 String (from XML)
---------------------------------
"AAAAAM3MTD7NzMw+I9sZP83MTD8AAIA/..."

This is text representation of binary data.

STEP 2: Decode to Binary Bytes
-------------------------------
Base64 → Binary conversion:

AAAA → 00 00 00 00
AM3M → CD CC 4C 3E
TD7N → CD CC CC 3E
zMw+ → 23 DB 19 3F
...

STEP 3: Unpack as IEEE 754 Floats
----------------------------------
Every 4 bytes = one 32-bit float (little-endian):

00 00 00 00 → 0.0
CD CC 4C 3E → 0.2
CD CC CC 3E → 0.4
23 DB 19 3F → 0.601
...

STEP 4: Result - Array of Numbers
----------------------------------
[0.0, 0.2, 0.4, 0.601, 0.8, 1.0, 1.2, ...]

These are the actual time points (in seconds) or response values (in nanometers).

================================================================================
KEY PARAMETERS CALCULATED FROM THIS DATA
================================================================================

From ASSOCIATION curve:
  • kon (M⁻¹s⁻¹) - association rate constant
  • Rmax (nm) - maximum binding capacity
  • Curve fit quality (R², chi-square)

From DISSOCIATION curve:
  • koff (s⁻¹) - dissociation rate constant
  • t1/2 (s) - half-life of antibody-antigen complex
  • Stability assessment

Combined:
  • KD = koff/kon (M) - equilibrium dissociation constant
  • Lower KD = tighter binding = better antibody
  • Typical good antibodies: KD < 10 nM
